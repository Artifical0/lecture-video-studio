使用说明

上传课件和讲稿，选一个声音，服务器就会逐页配音、翻页，生成带字幕的录课视频。生成期间可以关掉页面，回来在任务列表里下载。

1. 准备课件

推荐在 PowerPoint / WPS 里 另存为 PDF 再上传，画面和导出效果完全一致。也可以直接传 .pptx，服务器会用 LibreOffice 转换，复杂动画和特殊字体可能走样。动画不会保留，每页只显示最终画面。

2. 写讲稿

讲稿是 Markdown 文本，每页以 ## P页码｜标题 开头（“｜”是全角竖线），页码对应课件第几页。只朗读 ### 口播正文 和 ### 过渡 两节，其他小节（如讲解提示）不读。没写讲稿的课件页会被跳过。

# 第1讲｜课程名称

## P01｜封面
### 口播正文
同学们好，欢迎来到本课程的第一讲。
### 讲解提示（不朗读）
封面停留即可。
### 过渡
先看一下今天的路线图。

小技巧：句子以 。？！ 结尾，字幕也按句切分；一行一段，段间停顿稍长；某个词读音不对，就在讲稿里改写成想要的读法。

4. 添加音色

在“音色库”上传一段录音或视频（15–30 秒清晰讲话最好，背景安静）。服务器会自动挑出完整的句子，识别出对应文字；请核对文字和录音是否一致，不一致会影响效果。只上传已取得本人同意的声音。

5. 结果

每个任务产出：带字幕视频、无字幕视频和 .srt 字幕文件。视频保存在服务器上，直到有人删除；重要的成品请自己下载保存一份。
